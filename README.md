# 電荷實驗室 v6.0

正式網站：https://hikaruhen.github.io/staticElectricity/

預設滿版橫向操作，畫布在左、工具在右；手機直向可使用下方工具區。首次點擊模式或按「全螢幕」嘗試進入瀏覽器原生全螢幕，不攔截拖曳；不支援時維持滿版。旋轉、改尺寸及全螢幕切換保留電量、接地、物品與測驗紀錄。

模式：靜電、摩擦起電、自由操作起電、庫倫定律、測驗模式。

純 HTML/CSS/JavaScript。網站產物只含 index.html、style.css、app.js、explore.js、workbench.js、shell.js。
模型為教學示意，非完整電場、電容或真實時間模擬；塑膠採乾燥聚乙烯假設。導電球採相同有效容量，絕緣材質僅示意局部接觸轉移。原始教材、私有QA與備份不在網站產物中。

課程參考：05-115國中自然3上備課ch4-理化，第4-1節。
互動參考：https://phet.colorado.edu/zh_TW/simulations/balloons-and-static-electricity
全螢幕API：https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen
圖像與程式由本專案製作，無嵌入 PhET 程式。
