# 電荷實驗室

國中自然互動教具 v5.1。

正式網站：https://hikaruhen.github.io/staticElectricity/

- 靜電：氣球摩擦、電子轉移、同性相斥與牆面極化。
- 材質摩擦：毛皮、玻璃、塑膠各自拖入；塑膠採乾燥聚乙烯表面假設。
- 自由操作起電：可設定正負電量的外部導電球，配合接觸、感應與接地操作。
- 庫倫定律：拖曳電荷、電量與距離控制、力箭頭與基準倍數比較。
- 實作測驗：接觸起電與感應起電，依操作過程及最終狀態判定。

純 HTML/CSS/JavaScript。網站產物只包含 index.html、style.css、app.js、explore.js、workbench.js。

模型為教學示意；非完整電場、電容或真實時間模擬。外部導電球採相同有效容量，絕緣材質僅示意局部接觸轉移。球內固定符號每個代表2格，移動標記另顯示本次轉移量。原始教材不在網站產物中。

課程參考：05-115國中自然3上備課ch4-理化，第4-1節。
互動設計參考：https://phet.colorado.edu/zh_TW/simulations/balloons-and-static-electricity
圖像與程式由本專案製作，無嵌入 PhET 程式。
